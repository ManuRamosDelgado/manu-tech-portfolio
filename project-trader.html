MIL Trader

Sistema experimental de investigación de mercados usado como laboratorio de pipelines, simulación, observabilidad y control de riesgo.

SHADOW · Execution locked
Problema

Una oportunidad aparente no es beneficio ejecutable

Fees, slippage, latencia, estado obsoleto y sesgos de muestreo pueden convertir una señal atractiva en una operación negativa.

Decisión

Shadow-first

Separar investigación de ejecución. El sistema puede medir y acumular evidencia, pero la ejecución real permanece bloqueada.

Arquitectura

Datos → análisis → gates → evidencia

Collectors y probes alimentan análisis; los risk gates evalúan margen, frescura y seguridad; un circuit breaker corta ante fallos repetidos; la evidencia se conserva para decidir.

Implementación

TypeScript + Solidity controlado

El repositorio incluye lógica de investigación, dashboard, tests de seguridad y contratos de laboratorio. La autoridad financiera de la IA es 0.

Validación

Verificación fresca 04/10/2026

56/56 tests de aplicación PASS, 10/10 tests Solidity PASS, typecheck PASS y compilación PASS.

Resultado

El “no ejecutar” es una feature

Los probes siguen sin demostrar ventaja neta repetible. El sistema lo reconoce y mantiene el capital real fuera del alcance automático.
