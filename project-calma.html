CALMA World

Juego/experiencia de calma usado para demostrar frontend, iteración de producto, accesibilidad y construcción de una experiencia visual rica sin monetización basada en presión.

Build PASS
Problema

Un prototipo funcional no basta

La primera versión transmitía calma, pero la legibilidad de puzles y la calidad visual estaban lejos de un producto publicable.

Decisión

Elevar experiencia sin añadir presión

Se eliminan vidas, gemas, FOMO y compra de progreso. La evolución visual se apoya en mundos, senderos, refugio, recompensas decorativas y movimiento reducido.

Arquitectura

React + motor visual separado

Interfaz React/TypeScript/Vite combinada con PixiJS/WebGL para mundos y efectos; API independiente para flujos que requieren backend.

Implementación

Vertical slices antes de expandir

El mundo Musgo se usa como vertical slice premium; luego se incorporan avatar, recompensas y refugio antes de escalar el patrón al resto.

Validación

Pruebas y build frescos

El 04/10/2026 se validaron 8/8 tests web, 2/2 tests API y build de producción PASS.

Resultado

Amplitud de producto

El caso demuestra capacidad para iterar desde feedback, cuidar UX, accesibilidad y performance además de la arquitectura.
