Automation Lab

MIL House / Home Automation

Laboratorio personal para automatización doméstica, sensores y actuación física. Se usa como proyecto secundario para demostrar integración, troubleshooting y prudencia operacional.

CANARY
Problema

El mundo físico no tolera estados inventados

Una automatización doméstica debe distinguir entre intención, estado observado y acción realmente completada.

Decisión

Acceptance Gate A→D

Preflight y body model antes de deploy, Core solo si Gate A pasa, aceptación física posterior y estabilidad antes de declarar el sistema estable.

Arquitectura

Home Assistant + dispositivos + lógica

Home Assistant actúa como núcleo; sensores Zigbee y dispositivos aportan estado; la lógica condicional decide y verifica.

Implementación

Backups y hashes antes de cambios

Los cambios de Core se tratan como operaciones reversibles, con preflight, backups y verificación.

Validación

CANARY deliberado

El sistema no se declara estable mientras no pase la aceptación real de cuerpo, acciones, conversación y estabilidad.

Resultado

Troubleshooting aplicado

El laboratorio permite trabajar con latencias, sensores, condiciones nocturnas, estados y fallos que no aparecen en una demo puramente software.
